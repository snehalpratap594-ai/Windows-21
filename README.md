# Windows 21

A futuristic, interactive OS-style desktop prototype built as a single static web app.

## Included
- Windows 21 boot sequence with automatic desktop launch
- No login/sign-in screen
- Start menu, Search, taskbar and system tray
- File Explorer, Settings, AI Assistant, Calculator, Notepad, Photos, Media Player and App Store
- Notifications and Quick Settings
- Wi-Fi, Bluetooth, airplane mode, night light, brightness and volume controls
- Theme/accent switching
- Draggable, minimizable, maximizable and closable windows
- Power controls and system dialogs
- Virtual-desktop controls
- Keyboard shortcuts: Ctrl/Win+E, Ctrl/Win+I, Ctrl/Win+S, Alt+Tab, Ctrl/Win+Arrow
- Consistent glass/futuristic visual system

## Run
Open `index.html` in a browser, or enable GitHub Pages for the repository to host it as a static site.
